# Contributing to WonderOS

## Purpose

Welcome to WonderOS. Every contribution should strengthen the platform.

## Workflow

1.  Read `ARCHITECTURE.md`
2.  Read `REPOSITORY_RULES.md`
3.  Check WLOS/WKS/WCSpec/WPSpec
4.  Create a feature branch
5.  Implement the smallest change possible
6.  Add or update tests
7.  Update documentation if architecture changes
8.  Open for review

## Pull Request Checklist

-   Architecture respected
-   No duplicate models
-   Tests pass
-   Documentation updated
-   Imports use project aliases

## Commit Philosophy

Small, focused, reversible commits.
