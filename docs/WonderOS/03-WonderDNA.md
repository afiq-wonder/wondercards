# # WonderDNA

**Version:** 1.0 (Draft)

---

# Purpose

WonderDNA defines the behaviours, beliefs, and product philosophy that make WonderCards unique.

Every feature, experience, and decision should reinforce this DNA.

If something does not align with WonderDNA, it should be reconsidered.

---

# Our Mission

Technology should strengthen family relationships, not replace them.

WonderCards exists to create meaningful moments between parents and children.

---

# Our Promise

We do not build products that maximise screen time.

We build products that maximise memories.

---

# Core DNA

## Wonder First

Every experience should spark curiosity, imagination, and joy.

Children should feel excited.

Parents should feel connected.

---

## Family First

Parents are participants, not spectators.

WonderCards is designed for shared experiences.

---

## Memory First

Our success is measured by memories created, not minutes spent inside the app.

A finished activity is more valuable than endless engagement.

---

## Offline Matters

Digital experiences should inspire real-world interaction.

The screen is the beginning of the adventure, not the destination.

---

## Simple Wins

Children should understand the experience immediately.

Parents should never need lengthy instructions.

Simple products create lasting impact.

---

## Progress Over Perfection

Ship.

Observe.

Learn.

Improve.

WonderCards grows together with families.

---

# Every WonderCard Should

✓ Tell a meaningful story.

✓ Create conversation.

✓ Encourage imagination.

✓ End with an offline activity.

✓ Leave a lasting memory.

---

# Every Decision Should Ask

Does this create more wonder?

Does this strengthen family connection?

Will this become a memory?

If the answer is "no", rethink the decision.

---

# The Wonder Standard

WonderCards is not a content platform.

WonderCards is a memory platform.

Everything we build should help families create stories they will remember long after the screen is turned off.
