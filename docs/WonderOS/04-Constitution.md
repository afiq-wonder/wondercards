# WonderOS Constitution

**Version:** 1.0 (Draft)

---

# Purpose

The WonderOS Constitution defines the principles that guide every decision within WonderCards.

It is the highest level governance document for the project.

Whenever uncertainty exists, this Constitution takes precedence over implementation preferences.

---

# Principle 1 — Family Above Everything

Every decision should benefit families.

Short-term engagement must never compromise long-term relationships.

---

# Principle 2 — Wonder Before Complexity

Choose clarity over cleverness.

Choose delight over unnecessary features.

Choose simplicity over technical ego.

---

# Principle 3 — Build for the Long Term

Every system should be maintainable.

Every module should be replaceable.

Every decision should scale.

---

# Principle 4 — Documentation Before Assumptions

Knowledge belongs in documentation.

Important decisions should never exist only inside conversations.

---

# Principle 5 — One Source of Truth

Avoid duplication.

Avoid conflicting implementations.

Avoid multiple versions of the same knowledge.

---

# Principle 6 — AI is a Builder

AI is treated as a contributor to the project.

AI should understand:

- Vision

- Identity

- WonderDNA

- Repository structure

- Architecture

before writing code.

---

# Principle 7 — Small Steps, Continuous Progress

Prefer many small improvements over infrequent large rewrites.

Consistency compounds.

---

# Principle 8 — Quality is Non-Negotiable

Working software is required.

Readable code is expected.

Reliable tests are essential.

Documentation is mandatory.

---

# Principle 9 — Respect Existing Work

Improve before replacing.

Extend before rewriting.

Understand before refactoring.

---

# Principle 10 — Protect Wonder

Every release should strengthen the WonderCards experience.

Never sacrifice wonder for convenience.

Wonder is our competitive advantage.

---

# Decision Framework

When making decisions, ask:

1. Does this align with the Vision?

2. Does this reinforce WonderDNA?

3. Does this improve the family experience?

4. Is it maintainable?

5. Is it documented?

If any answer is "no", reconsider the decision.

---

# Final Principle

WonderCards is built to become a lasting legacy.

Every contribution should leave the project stronger than it was before.
