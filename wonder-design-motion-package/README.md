# Wonder Design + Motion Foundation v1

A dependency-free visual and motion foundation for WonderCards.

## Design principles

1. The app should feel like a living storybook, not a dashboard.
2. Movement must be gentle and supportive, never distracting.
3. Every World has its own host; Coral is the host of Coral World.
4. UI components remain shared across Worlds.
5. Each World can later replace colours, backgrounds, host assets, and ambient effects through configuration.
