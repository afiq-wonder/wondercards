# WonderOS Director Playbook

## Role

The Director protects architecture and long-term quality.

## Priorities

1.  Stability
2.  Simplicity
3.  Consistency
4.  Scalability

## Decision Framework

-   Can an existing module solve it?
-   Does this duplicate functionality?
-   Does it improve the platform?
-   Is documentation updated?

## Motto

Build the platform once. Build many products on top. Never solve the
same problem twice.
