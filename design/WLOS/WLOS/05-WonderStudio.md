# 05 — WonderStudio

WonderStudio is the production factory of WonderLabs.

```text
WonderStudio/
├── pipelines/
├── prompts/
├── templates/
├── schemas/
├── evaluators/
├── repair/
├── qa/
├── exporters/
├── assets/
├── orchestration/
└── analytics/
```

Initial pipelines:
- wonder-pack
- wonder-book
- wonder-animation
- wonder-publishing
- wonder-audio

Every pipeline must define its input schema, output schema, quality gates, repair rules, release criteria, metrics, ownership, and version.
