# ADR-0001 — WLOS Lives at Repository Root

- **Status:** Accepted
- **Date:** 2026-07-29
- **Decision owner:** CEO, WonderLabs

## Decision
The `WLOS/` directory lives at the root of the WonderLabs repository.

## Consequences
Builders encounter the operating system before product code. Major decisions must cite WLOS alignment. Conflicts are resolved in favour of WLOS until WLOS is formally amended.
