# ADR-0002 — WLOS Is the Single Source of Truth

- **Status:** Accepted
- **Date:** 2026-07-29
- **Decision owner:** CEO, WonderLabs

WLOS is authoritative for company philosophy, governance, operating model, architecture principles, production standards, quality systems, and leadership doctrine.

When conflict appears:
1. Verify the conflict.
2. Follow WLOS.
3. Open an RFC if WLOS may need amendment.
4. Update dependent artefacts after approval.
