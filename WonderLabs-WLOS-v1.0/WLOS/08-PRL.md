# 08 — Production Readiness Level (PRL)

| Level | State |
|---:|---|
| PRL 1 | Idea |
| PRL 2 | Creative brief |
| PRL 3 | Draft generated |
| PRL 4 | Internal QA passed |
| PRL 5 | Testing pool |
| PRL 6 | Revision completed |
| PRL 7 | Approved |
| PRL 8 | Production ready |
| PRL 9 | Published and measured |

PRL records evidence of readiness, not optimism.

Each transition requires entry criteria, exit criteria, evidence, owner, and timestamp.
