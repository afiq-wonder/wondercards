# 04 — Wonder Production System (WPS)

```text
Creative Brief
→ Schema Validation
→ Generate
→ Evaluate
→ Repair
→ Wonder Quality Gate
→ Wonder Confidence Score
→ Production Readiness
→ Package
→ Publish
→ Measure
→ Improve
```

## Rules
- No hidden production path.
- Every output has an owner, version, status, and provenance.
- Failed gates must produce actionable reasons.
- Repeated failure must improve the pipeline.
- Published outputs must remain reproducible from approved inputs and versions.
