# 12 — Governance

WLOS is the highest internal operating authority.

```text
Proposal
→ RFC
→ Review
→ Decision
→ WLOS or ADR update
→ Implementation
→ Validation
→ Release
```

Use ADRs for durable architecture and operating decisions.

Use RFCs for proposed material changes requiring discussion.

Emergency exceptions must be time-limited, documented, owned, and followed by a permanent system decision.
